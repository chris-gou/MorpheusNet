# PCB

Manufacturing files for the acquisition and power-management board used in the sleep headband (ADS1299 analog front end + Teensy 4.0).

Contents:
- `Gerber_PCB1_2023-02-08.zip` - Gerber fabrication files (copper, mask, silkscreen, drill).
- `BOM_Board1_PCB1_2024-02-28.xlsx` - bill of materials.
- `PickAndPlace_PCB1_2024-02-28.xlsx` - pick-and-place / centroid file for assembly.
